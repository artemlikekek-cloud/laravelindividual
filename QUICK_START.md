## 🎯 Быстрые тесты

### 1. Проверка валидации (2 мин)
```
1. Открыть http://localhost:8000/booking
2. Заполнить форму
3. Ввести телефон: "123" (неправильный)
4. Должна появиться ошибка: "Неверный формат телефона..."
```

### 2. Отзывы (3 мин)
```
1. Открыть http://localhost:8000/
2. Прокрутить вниз к форме отзыва
3. Заполнить и отправить
4. Отзыв попадёт на модерацию (видим сообщение)
5. Зайти в /admin/reviews
6. Одобрить отзыв (кнопка "Одобрить")
7. Вернуться на главную - отзыв появился!
```

### 3. Архив (2 мин)
```
1. Открыть http://localhost:8000/admin/dashboard
2. Видим только active записи
3. Нажать "Архив"
4. Видим ВСЕ записи
5. Ввести в фильтр телефон/email клиента
6. Нажать "Применить"
7. Видим все заказы этого клиента
```

## 🔥 Самое важное

### Для администратора:

**Каждый день:**
1. Открыть `/admin/dashboard` → обработать новые заявки
2. Открыть `/admin/reviews` → модерировать отзывы

**По запросу клиента:**
1. Открыть `/admin/archive`
2. Ввести телефон/email в фильтр
3. Увидеть всю историю клиента

**Завершение работы:**
1. Найти запись в дашборде
2. Изменить статус на "Завершена"
3. Запись уйдёт в архив автоматически

## 💡 Полезные команды

```bash
# Запустить сервер
php artisan serve

# Посмотреть все маршруты
php artisan route:list

# Посмотреть админ маршруты
php artisan route:list --path=admin

php artisan migrate:fresh

```
