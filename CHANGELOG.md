# История изменений

## [09.11.2026] - Обновление функционала

### ✅ Добавлено

#### 1. Валидация контактных данных
- **Телефон**: Строгая проверка формата (regex паттерн для российских номеров)
  - Поддержка форматов: `+7XXXXXXXXXX`, `8XXXXXXXXXX`, `+7 (XXX) XXX-XX-XX`
  - Понятные сообщения об ошибках
- **Email**: Усиленная валидация с проверкой DNS (`email:rfc,dns`)

#### 2. Система отзывов
- **База данных**: Новая таблица `reviews`
- **Публичная часть**:
  - Форма добавления отзыва на главной странице
  - Отображение последних 10 одобренных отзывов
  - Рейтинг от 1 до 5 звёзд
  - Валидация (мин. 10 символов текста)
- **Админ-панель**:
  - Страница управления отзывами `/admin/reviews`
  - Модерация (одобрение/скрытие)
  - Удаление отзывов
  - Цветовая индикация статуса

#### 3. Фильтрация активных записей
- Дашборд показывает только активные заказы:
  - `pending` (Ожидает подтверждения)
  - `confirmed` (Подтверждена)
- Завершённые и отменённые перемещены в архив

#### 4. Архив заказов с фильтрацией
- **Новая страница**: `/admin/archive`
- **Фильтры**:
  - По номеру телефона (частичное совпадение)
  - По email (частичное совпадение)
  - По статусу (все статусы)
- **Возможности**:
  - Просмотр всех заказов клиента
  - История обслуживания
  - Изменение статуса прямо из архива
  - Удаление записей
