## Навигация в админ-панели

Теперь в админ-панели есть три раздела с удобной навигацией:

1. **📊 Активные записи** (`/admin/dashboard`)
   - Только pending и confirmed
   - Быстрый доступ к текущим заказам

2. **📦 Архив** (`/admin/archive`)
   - Все записи (включая completed и cancelled)
   - Расширенные фильтры поиска
   - История всех заказов клиентов

3. **⭐ Отзывы** (`/admin/reviews`)
   - Управление отзывами
   - Модерация (одобрение/скрытие)
   - Удаление отзывов

## Структура БД

### Новая таблица `reviews`

```sql
- id (bigint, primary key)
- client_name (string)
- client_email (string)
- review_text (text)
- rating (integer, 1-5)
- is_approved (boolean, default: false)
- created_at (timestamp)
- updated_at (timestamp)
```

## Маршруты

### Публичные:
```php
GET  /                 - главная страница с отзывами
POST /reviews          - сохранение отзыва
```

### Админ (требуется авторизация):
```php
GET    /admin/archive              - архив всех записей
GET    /admin/reviews              - управление отзывами
POST   /admin/reviews/{id}/approve - одобрить/скрыть отзыв
DELETE /admin/reviews/{id}         - удалить отзыв
```
