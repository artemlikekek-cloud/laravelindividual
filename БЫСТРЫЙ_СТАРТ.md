# ⚡ БЫСТРЫЙ СТАРТ - Установка за 2 минуты

## 🎯 Команды для копирования

Просто скопируй и вставь блоками в PowerShell / Terminal:

### 1️⃣ Клонирование и установка

```bash
# Замени URL на свой репозиторий!
git clone https://github.com/ВАШ_USERNAME/sto-project.git
cd sto-project
composer install
```

### 2️⃣ Настройка окружения

```bash
copy .env.example .env
php artisan key:generate
```

### 3️⃣ База данных

```bash
type nul > database\database.sqlite
php artisan migrate:fresh --seed
```

### 4️⃣ Запуск

```bash
php artisan serve
```

## ❗ Если что-то не работает

### Проблема: "Class 'PDO' not found"

```bash
# Найди php.ini и раскомментируй:
extension=pdo_sqlite
extension=sqlite3
```

### Проблема: "No application encryption key"

```bash
php artisan key:generate
```

### Проблема: Порт 8000 занят

```bash
php artisan serve --port=8080
```

### Проблема: Не работает после изменений

```bash
php artisan config:clear
php artisan cache:clear
php artisan migrate:fresh --seed
```

## 📝 Что настроить в .env

После `copy .env.example .env` открой `.env` и проверь:

```env
# Название проекта
APP_NAME="СТО Онлайн-запись"

# База данных (SQLite - проще всего)
DB_CONNECTION=sqlite

# Сессии
SESSION_DRIVER=database
```

**Всё остальное уже настроено!**
