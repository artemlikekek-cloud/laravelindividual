# 🚗 Руководство по защите индивидуального проекта СТО

## 📋 Описание проекта

**Система онлайн-записи на автосервис (СТО)** с административной панелью.

### Основной функционал:
- ✅ Онлайн-запись клиентов на услуги
- ✅ Система отзывов с модерацией
- ✅ Административная панель для управления записями
- ✅ Проверка доступности временных слотов

## ⚙️ REPOSITORY PATTERN

### Зачем нужен?

❌ **Без Repository:**
```php
// В контроллере напрямую работа с БД
$appointments = Appointment::where('status', 'pending')->get();
```
Проблемы:
- Дублирование кода
- Сложно тестировать
- Тесная связь с БД

✅ **С Repository:**
```php
// В контроллере
$appointments = $this->appointmentRepository
                     ->getActiveAppointments();
```

### Как работает?

```
1. Создаем интерфейс (Contract):

interface AppointmentRepositoryInterface {
  public function create(array $data);
  public function getActiveAppointments(int $perPage);
}

2. Создаем реализацию:

class AppointmentRepository 
  implements AppointmentRepositoryInterface {
  
  public function create(array $data) {
    return Appointment::create($data);
  }
  
  public function getActiveAppointments(int $perPage) {
    return Appointment::whereIn('status', 
                        ['pending', 'confirmed'])
                      ->paginate($perPage);
  }
}

3. Регистрируем в AppServiceProvider:

$this->app->bind(
  AppointmentRepositoryInterface::class,
  AppointmentRepository::class
);

4. Используем в контроллере через DI:

public function __construct(
  private AppointmentRepositoryInterface $repo
) {}
```

**Преимущества:**
- ✅ Легко заменить реализацию (например, перейти на MongoDB)
- ✅ Легко тестировать (мокируем интерфейс)
- ✅ Чистый код в контроллерах

## 🔄 SERVICE LAYER

### AppointmentService

**Зачем?** Инкапсуляция бизнес-логики.

```php
class AppointmentService {
  public function createAppointment(array $data) {
    // 1. Получить услуги
    $services = $this->serviceRepository
                     ->findByIds($data['services']);
    
    // 2. Рассчитать стоимость и длительность
    $totalPrice = $services->sum('price');
    $totalDuration = $services->sum('duration_minutes');
    
    // 3. Проверить конфликты времени
    if ($this->timeSlotService->checkConflict(...)) {
      return ['success' => false];
    }
    
    // 4. Создать запись
    $appointment = $this->appointmentRepository->create([
      'total_price' => $totalPrice,
      'total_duration_minutes' => $totalDuration,
      // ...
    ]);
    
    // 5. Привязать услуги
    $this->appointmentRepository
         ->attachServices($appointment, $data['services']);
    
    return ['success' => true];
  }
}
```

### TimeSlotService

Проверяет доступность временных слотов:

```php
public function getAvailableSlots($date, $duration) {
  1. Получить рабочие часы (9:00 - 18:00)
  2. Разбить на слоты по 15 минут
  3. Получить существующие записи на эту дату
  4. Вычесть занятое время
  5. Вернуть доступные слоты
}

public function checkConflict($date, $time, $duration) {
  1. Новая запись: 10:00 - 11:30 (90 мин)
  2. Проверить: есть ли записи, которые:
     - Начинаются в период [10:00 - 11:30]
     - ИЛИ заканчиваются в период [10:00 - 11:30]
     - ИЛИ полностью покрывают период
  3. Если есть → конфликт
}
```

## 🌐 NGINX + PHP-FPM

### Как они взаимодействуют?

```
┌─────────────────────────────────────────────┐
│         Docker Container                    │
│                                             │
│  ┌─────────────────────────────────────┐  │
│  │   Supervisord (главный процесс)     │  │
│  │                                     │  │
│  │   ┌───────────┐   ┌─────────────┐  │  │
│  │   │  Nginx    │   │  PHP-FPM    │  │  │
│  │   │  :8080    │   │  :9000      │  │  │
│  │   └─────┬─────┘   └──────▲──────┘  │  │
│  │         │                 │         │  │
│  │         └─────FastCGI─────┘         │  │
│  └─────────────────────────────────────┘  │
└─────────────────────────────────────────────┘
         ▲                         │
         │                         │
    HTTP Request              HTTP Response
```

### Nginx конфигурация:

```nginx
server {
  listen 8080;                    # Слушать на порту 8080
  root /app/public;               # Корневая папка
  index index.php;                # Главный файл
  
  # Основной роутинг
  location / {
    try_files $uri $uri/ /index.php?$query_string;
    # 1. Проверить файл напрямую
    # 2. Проверить папку
    # 3. Отправить в index.php (Laravel)
  }
  
  # PHP файлы
  location ~ \.php$ {
    fastcgi_pass 127.0.0.1:9000;  # Передать в PHP-FPM
    fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
    include fastcgi_params;
  }
  
  # Безопасность: блокировать .env, .git
  location ~ /\.(?!well-known).* {
    deny all;
  }
}
```

## 🎯 КЛЮЧЕВЫЕ МОМЕНТЫ ДЛЯ ЗАЩИТЫ

### 1. **Зачем Repository Pattern?**
- Изоляция от БД
- Легкость тестирования
- Соблюдение SOLID принципов

### 2. **Зачем Service Layer?**
- Вся бизнес-логика в одном месте
- Контроллеры остаются тонкими
- Переиспользование логики

### 3. **Как работает Nginx?**
- Принимает HTTP-запросы
- Отдает статику напрямую
- PHP файлы передает в PHP-FPM через FastCGI

### 4. **Как работает роутинг Laravel?**
- `routes/web.php` → определяет маршруты
- Laravel ищет совпадение
- Вызывает метод контроллера
- Контроллер возвращает view

### 5. **Blade Templates**
- Шаблонизатор Laravel
- Поддерживает наследование и включение
- Автоматически экранирует вывод
- Компилируется в чистый PHP

### 6. **Безопасность**
- CSRF токены
- Валидация на сервере
- Middleware для авторизации
- Защита от SQL Injection и XSS

## 📝 ЧАСТЫЕ ВОПРОСЫ НА ЗАЩИТЕ

**Q: Почему использовали Repository Pattern?**
> A: Для отделения логики работы с БД от бизнес-логики. Это упрощает тестирование и позволяет легко менять источник данных.

**Q: Как проверяется доступность времени?**
> A: TimeSlotService получает все записи на выбранную дату, вычисляет занятые интервалы и проверяет пересечения с новой записью.

**Q: Почему Nginx + PHP-FPM, а не встроенный сервер PHP?**
> A: PHP-FPM работает как процесс-менеджер, эффективнее использует ресурсы, быстрее обрабатывает запросы. Nginx отдает статику без PHP.

**Q: Как защищены пароли?**
> A: Laravel использует bcrypt хеширование. Пароли никогда не хранятся в открытом виде.

**Q: Что делает Supervisord?**
> A: Управляет процессами Nginx и PHP-FPM в контейнере. Автоматически перезапускает их при падении.
