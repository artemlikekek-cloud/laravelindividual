# Проект: Система онлайн-записи на СТО

## Описание проекта
Веб-приложение на Laravel для онлайн-записи клиентов на автосервис (СТО). Клиенты могут видеть свободное время, выбирать услуги и записываться на обслуживание.

## Основные функции

### 1. Для клиентов (пользователей)
- **Главная страница** с информацией о СТО
- **Страница записи** с выбором:
  - Типа услуги (диагностика, ремонт, ТО, шиномонтаж и т.д.)
  - Даты записи
  - Свободного времени в выбранную дату
- **Калькулятор услуг** - показывает список выбранных услуг, время на каждую и общее время
- **Форма записи** - ввод контактных данных (имя, телефон, email, марка авто)
- **Подтверждение записи** - уведомление об успешной записи

### 2. Для администратора (через middleware)
- **Панель администратора** (защищена middleware аутентификации)
- **Просмотр всех записей** по датам
- **Управление графиком работы** (установка рабочих часов, выходных)
- **Управление услугами** (название, длительность, цена)
- **Управление записями** (подтверждение, отмена, редактирование)

## Технические требования

### База данных (SQLite)
**Таблица `services` (услуги):**
- id
- name (название услуги)
- duration_minutes (длительность в минутах)
- price (цена)
- description (описание)
- is_active (активна ли услуга)
- created_at, updated_at

**Таблица `appointments` (записи):**
- id
- client_name (имя клиента)
- client_phone (телефон)
- client_email (email)
- car_model (марка и модель авто)
- appointment_date (дата записи)
- appointment_time (время записи)
- total_duration_minutes (общая длительность)
- total_price (общая стоимость)
- status (pending/confirmed/completed/cancelled)
- notes (примечания)
- created_at, updated_at

**Таблица `appointment_services` (связь записей и услуг):**
- id
- appointment_id
- service_id
- created_at, updated_at

**Таблица `working_hours` (рабочие часы):**
- id
- day_of_week (0-6, где 0 = воскресенье)
- start_time (время начала работы)
- end_time (время окончания работы)
- is_working (рабочий/выходной день)
- created_at, updated_at

**Таблица `users` (администраторы):**
- Использовать стандартную таблицу Laravel
- email: admin@sto.local
- password: admin123 (для разработки)

### Middleware
1. **AuthMiddleware** - проверка авторизации для админ-панели
2. **AdminMiddleware** - проверка прав администратора
3. **ThrottleMiddleware** - ограничение запросов (защита от спама при записи)

### Маршруты (routes/web.php)

**Публичные:**
- GET `/` - главная страница
- GET `/booking` - страница записи
- POST `/booking` - создание записи
- GET `/services` - список услуг (AJAX)
- GET `/available-times` - доступное время (AJAX)

**Защищенные (admin):**
- GET `/admin/login` - страница входа
- POST `/admin/login` - аутентификация
- GET `/admin/dashboard` - панель управления
- GET `/admin/appointments` - все записи
- GET `/admin/appointments/{id}` - детали записи
- PUT `/admin/appointments/{id}` - обновление записи
- DELETE `/admin/appointments/{id}` - удаление записи
- GET `/admin/services` - управление услугами
- POST `/admin/services` - создание услуги
- PUT `/admin/services/{id}` - обновление услуги
- DELETE `/admin/services/{id}` - удаление услуги
- GET `/admin/working-hours` - управление графиком
- POST `/admin/working-hours` - сохранение графика

### Frontend

- **TailwindCSS** или **Bootstrap** для стилей
- **Alpine.js** или **Vue.js** для интерактивности
- **AJAX** для загрузки доступного времени без перезагрузки страницы

### Логика расчета времени
1. Клиент выбирает услуги из списка
2. Система суммирует длительность всех услуг
3. При выборе даты показываются слоты времени:
   - Начало слота = возможное время начала
   - Длительность слота = сумма длительностей услуг
   - Показываются только слоты, которые умещаются в рабочее время
   - Не показываются занятые слоты

**Пример:**
- Рабочий день: 9:00 - 18:00
- Выбраны услуги: Диагностика (30 мин) + Замена масла (45 мин) = 75 минут
- Уже есть запись: 10:00-11:00
- Доступное время: 9:00, 11:00, 12:00, 13:00, 14:00, 15:00, 16:00 (не 16:30, т.к. не успеет до 18:00)
