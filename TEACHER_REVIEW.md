### 3. Фильтрация в админке - только активные заказы ✔️

**Реализация:**

### 4. Архив с фильтрацией по телефону/email ✔️

**Реализация:**

#### Основной функционал:
- Новая страница `/admin/archive`
- Отображение ВСЕХ заказов (включая completed, cancelled)
- Кнопка "Архив" в навигации админ-панели

#### Фильтры:
- **По номеру телефона** - частичное совпадение (поиск по подстроке)
- **По email** - частичное совпадение
- **По статусу** - выбор из списка (все/pending/confirmed/completed/cancelled)
- Возможность комбинирования фильтров
- Кнопка "Сбросить" для очистки

#### Функции:
- Таблица с расширенной информацией
- Счётчик найденных записей
- Изменение статуса прямо из архива
- Удаление записей
- Пагинация с сохранением фильтров

**Файлы:**
- Контроллер: `app/Http/Controllers/AdminController.php` (метод `archive()`)
- Репозиторий: `app/Repositories/AppointmentRepository.php` (метод `query()`)
- Сервис: `app/Services/AppointmentService.php` (метод `getAllAppointmentsQuery()`)
- Представление: `resources/views/admin/archive.blade.php`
- Маршрут: `routes/web.php` (`GET /admin/archive`)

**Проверка:**
```
1. Открыть http://localhost:8000/admin/archive
2. Увидеть все записи
3. Ввести в фильтр телефон: "+7999"
4. Нажать "Применить"
5. Увидеть только записи с этим номером
```

## 🎯 Концепция "Таблица пользователей"

**Интерпретация задания:**
> "...таблицу юзер считай создать где будут заказы человека"

Реализовано через **Архив с фильтрацией**:
- Вместо отдельной таблицы users с заказами внутри, создан архив
- Администратор может искать клиента по телефону/email
- Система отображает ВСЕ заказы найденного клиента
- Это более гибкое решение, чем статичная таблица users

**Преимущества подхода:**
✅ Не нужно регистрировать каждого клиента как пользователя  
✅ Быстрый поиск по телефону/email  
✅ История всех визитов клиента в одном месте  
✅ Фильтрация по статусам
